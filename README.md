# nasbot-site

Páginas públicas de **NASBot**, un bot de Telegram personal que administra un
NAS hogareño: inicio, política de privacidad y condiciones del servicio.

Existen porque la consola de Google Cloud las pide para publicar la pantalla de
consentimiento de OAuth. El bot usa el permiso `gmail.metadata` (remitente,
asunto, fecha y etiquetas; sin acceso al cuerpo de los mensajes) para armar un
resumen diario de correo.

Publicado con GitHub Pages: <https://ifacuferra.github.io/nasbot-site/>
